# 개발 환경 설정

## 개발 툴 설치

- Chocolatey
  - 홈페이지: https://chocolatey.org/

```bash
# Power Shell 관리자 권한으로 실행
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# 이미 존재한다고 나온다면 삭제 후 다시 설치
Remove-Item -Recurse -Force C:\ProgramData\chocolatey

# 설치 확인
choco --version
```

- FVM
  - 홈페이지: https://fvm.app/

```bash
# FVM 설치
choco install fvm

# 설치 확인
fvm --version

# 설치 가능한 Flutter 버전 확인
fvm releases

# Flutter 설치
fvm install stable

# Flutter 명령어
fvm flutter doctor # 환경 확인
fvm flutter --version # 버전 확인
fvm flutter devices # 연결된 디바이스 확인
fvm flutter emulators # 설치된 에뮬레이터 확인
fvm flutter emulators --launch 에뮬레이터ID # 에뮬레이터 실행
fvm flutter create my_app # 프로젝트 생성
fvm flutter create . # 현재 폴더에 프로젝트 생성
fvm flutter pub get # 패키지 설치
fvm flutter pub add dio # 패키지 추가
fvm flutter pub remove dio # 패키지 제거
fvm flutter run # 앱 실행
fvm flutter run -d 디바이스ID # 실행 가능한 디바이스 지정
fvm flutter analyze # 코드 검사
fvm flutter test # 테스트
fvm flutter clean # 캐시/빌드 파일 정리
fvm flutter build apk # Android APK 빌드
fvm flutter build appbundle # Android App Bundle 빌드
fvm flutter build web # Web 빌드
```

## 프로젝트 만들기

```bash
# FVM이 관리하는 공용 SDK 저장소에 Flutter 버전을 설치
fvm install stable

# 프로젝트 폴더 생성
mkdir app
cd app

# 특정 Flutter 버전 사용
fvm use stable

# Flutter 프로젝트 생성
fvm flutter create .
fvm flutter doctor

# Android SDK 라이센스 허용
flutter doctor --android-licenses
```
