# 에뮬레이터

## 1. Android SDK

Android Studio는 Android SDK 안의 여러 도구를 설치하고 관리해주는 IDE이다.

- `emulator/emulator.exe`: Android 가상 기기를 실행하는 프로그램
- `platform-tools/adb.exe`: 실행 중인 Android 기기나 에뮬레이터와 통신하는 도구
- `system-images/`: Android OS 이미지(Android 15, API 35 같은 실제 가상 OS 이미지)

```
Android SDK/
├─ emulator/
│  └─ emulator.exe
│
├─ platform-tools/
│  └─ adb.exe
│
├─ cmdline-tools/
│  └─ ...
│
├─ platforms/
├─ build-tools/
└─ system-images/
```

### 1-1. 에뮬레이터 명령어

```bash
# 에뮬레이터 실행 경로
# C:\Users\User\AppData\Local\Android\Sdk\emulator\emulator.exe

# 에뮬레이터 목록
emulator -list-avds

# 에뮬레이터 실행
emulator -avd Pixel_8_API_35
```
